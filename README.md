# Ecommerce-management-system-

🛒 E-commerce SQL Project (Products, Orders, Customers)

This is a comprehensive SQL-based project to simulate a robust E-commerce database. It handles core online retail operations, including customer accounts, product catalogs, multi-item orders, and payment transactions through a relational database schema and a set of advanced analytical queries.

# 📁 Project Structure
ecommerce_database.sql – Full schema (CREATE TABLE) and analytical SQL queries.

# 🧱 Tables
Customers – Stores basic customer account info.

CustomerAddresses – Stores multiple shipping addresses for each customer.

Categories – Stores product categories and sub-categories.

Products – Stores product details, price, and stock quantity.

Orders – Tracks the "header" of a customer's order.

OrderItems – Tracks the specific products and quantities for each order.

Payments – Handles payment info and transaction status.

# 🧪 Sample SQL Queries Included
Top 5 Best-Selling Products

Total Revenue by Product Category

Monthly Sales Growth Report (using CTEs)

High-Value Customer Identification

Customers for Re-engagement (e.g., no recent orders)

# ⚙️ How to Run
Use any SQL client (MySQL, SQLite, or DB Browser for SQLite).

Import or paste ecommerce_database.sql into your query window.

Execute the schema and try out the queries.

# 🚀 Features
Normalized relational schema (7 tables)

Advanced analytical queries (CTEs, Window Functions, Joins)

Handles complex logic (sub-categories, inventory, multi-item orders)

Can be extended with INSERTs, triggers, views, and procedures.
